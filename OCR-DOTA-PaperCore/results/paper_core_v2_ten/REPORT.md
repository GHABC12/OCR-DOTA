# OCR-DOTA PaperCore V2 十数据集快速实验报告

## 协议

- 输出目录：`OCR-DOTA-PaperCore/results/paper_core_v2_ten/`
- 版本：`paper-core-v2-ten-prereg-1`
- 精度：FP32；global seed=1；Legacy DOTA 状态与原始 DOTA 基线一致。
- Posterior：`direct_prior`，冻结 `gamma=0.0`（因此严格等价于 Base）。
- Responsibility：`gate_only`，冻结 `delta=1.0`。
- 所有数据集均使用同一缓存、固定顺序和冷启动；标签只在预测和更新完成后用于评估。

Posterior 的结果与 Base 完全相同（全量 `Δcorrect=0`、interaction=0），因为预注册搜索中 Posterior 没有找到满足条件的正收益配置，最终按协议冻结为 `gamma=0`。因此本轮可复现的增益全部来自 Responsibility；它在 Dev-5 为 +95 个样本，在 Eval-5 为 +12 个样本。Responsibility 的错误类别责任质量指标同时改善（例如 DTD 的 WRM 从 69.6033 降至 65.6202，EuroSAT 从 63.7688 降至 54.4708）。

## 冷启动复现

DTD 与 EuroSAT 均按冻结配置完成第二次独立冷启动。两次运行的正确数、预测 SHA256、trajectory SHA256、state SHA256、compatibility SHA256 和样本数均完全一致；`final/verification.json` 状态为 `passed`。
